## 集計方法

Bot が回答を返すたびに `app/api/chat.py` から `save_query_log()` が呼ばれ、
Upstash Redis のリスト `query_log` と Railway の標準出力に1件ずつ記録される。
本レポートはそのリストを `scripts/usage_report.py` で集計したもの。
